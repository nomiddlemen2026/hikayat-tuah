# Hikayat Tuah: Quest for the Keris Taming Sari

A free, original 3D action RPG inspired by the Malay legend of Hang Tuah. Play it in your browser on a phone or computer, with no install and no account. Progress saves in your browser.

Built with plain JavaScript and [Three.js](https://threejs.org) (MIT). All art is generated in code.
